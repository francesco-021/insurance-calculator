# insurance-calculator

HTML5 calculator for a car insurance. user enter: 

* age 
* kw of the car
* number of years of driving license
* price of the new car
* coverage (only third party, third party fire and theft, fully comprehensive)

calculator will immedialy return the price of the insurance based on the data entered by the user.

##  tech stacks 

the project is built using htlm, css and javascript. single-page HTML5 application with no backend
